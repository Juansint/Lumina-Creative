# Lumina Kreative

Web multipágina para una agencia creativa ficticia, maquetada desde cero con **HTML y CSS**.

## Páginas

- **Inicio** (`index.html`)
- **Sobre nosotros** (`about.html`)
- **Contacto** (`contact.html`) con formulario

## Tecnologías

`HTML` `CSS`

## Ejecutar en local

Clona el repositorio y abre `index.html` en el navegador.
